# 海克斯参谋 · 电脑桥

阅读器上的「海克斯参谋」要跟你当前对局，必须在游戏电脑上跑这个桥。国服客户端只在本机 127.0.0.1 开口，阅读器访问不到，所以不能只装 xtapp。

本目录只有运行桥所需文件，不需 pip。

## 你需要

- Windows 10/11 游戏电脑
- Python 3（https://www.python.org/downloads/ ）安装时勾选 **Add python.exe to PATH**
- 已登录的英雄联盟客户端（国服 WeGame 或国际服）
- 阅读器与电脑同一 Wi-Fi（不要访客网络）
- 阅读器已安装「海克斯参谋」

## 步骤

1. 把本仓库下载为 ZIP 并解压到游戏电脑，例如 `D:\海克斯参谋`。文件夹里应有 `bridge.py` 和 `start.cmd`。
2. 安装 Python 3，勾选 Add python.exe to PATH。装完新开一个命令行，输入 `python --version` 能看到 3.x。
3. 打开并登录英雄联盟客户端。
4. 双击 `start.cmd`。它会结束占用 18765 端口的旧进程，并尝试放行火墙。
5. 浏览器应打开桥的页面，大字是局域网地址，例如 `192.168.1.7`。
   - 绿色 + 账号：已扫到客户端
   - 一直「等待」或「扫描」：任务管理器结束全部 `python.exe` / `pythonw.exe`，再双击 `start.cmd`
6. 阅读器连同一 Wi-Fi。安装应用时把该 IP 填进「电脑局域网地址」。
7. **不要**填 `127.0.0.1`（那是电脑自己，阅读器连不上）。**不要**加 `:18765`。
8. 只填这一次。以后每次打游戏：先开客户端，再开 `start.cmd`，阅读器会自动跟对局。

## 备选：从阅读器拷桥

没下载本仓库时：先打开一次应用 → USB 接阅读器 → `AppFiles/lol_guide/` 里的 `bridge.py`、`start.cmd` 拷到电脑，以后步骤相同。

## 排除

| 现象 | 处理 |
| --- | --- |
| 双击 start.cmd 闪一下消失 | 没装 Python 或没勾 PATH，重装 Python |
| 浏览器打不开 / 无法访问 | 只用本目录这一份 start.cmd，先结束旧 python |
| 一直等待客户端 | 客户端要已登录；等几秒；看页面灰色小字 |
| 阅读器连不上 | 同 Wi-Fi；填的是浏览器里那串 192.168，不是 127.0.0.1 |
| 只有海克斯大乱斗推荐 | 峡谷 / 人机不出海克斯清单，这是设计 |

桥只读客户端提供的本地接口，不注入、不改游戏文件。
